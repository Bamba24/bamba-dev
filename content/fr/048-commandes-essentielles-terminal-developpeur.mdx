# Commandes du Terminal : Le Guide Ultime du Développeur

« *Passer cinq minutes à cliquer dans une arborescence de dossiers pour trouver un fichier, ou taper une commande de trois mots qui s'exécute en 20 millisecondes ?* »

Le terminal n'est pas un vestige des années 1970 : c'est l'outil de productivité le plus puissant et le plus rapide jamais inventé pour les ingénieurs logiciels.

Les développeurs juniors ont tendance à tout faire à la souris à travers des interfaces graphiques lourdes. Mais dès que vous devez automatiser un déploiement, inspecter une API distante ou déboguer un conteneur, **la ligne de commande (CLI)** redevient le seul langage universel.

Dans ce guide pratique, nous allons explorer les commandes fondamentales du terminal, maîtriser les raccourcis clavier qui vous feront gagner des heures chaque semaine, manipuler les variables d'environnement et créer des alias sur-mesure.

## 1. Pourquoi le Terminal surpasse l'Interface Graphique (GUI)

L'interface graphique (GUI) est conçue pour la découverte visuelle ; le terminal (CLI) est conçu pour la **vitesse, la composition et l'automatisation**.

Trois raisons majeures justifient de dominer le terminal :
1. **Composabilité infinie** : Vous pouvez assembler dix commandes avec des pipes (`|`) pour transformer un flux de données sans écrire une seule ligne de code.
2. **Reproductibilité totale** : Une commande ou un script bash s'exécute de manière identique sur votre MacBook, sur une machine Windows via WSL2 ou sur un serveur Linux en Virginie.
3. **Consommation de ressources nulle** : Pas de fenêtres gourmandes en mémoire RAM, le terminal consomme quelques mégaoctets et démarre instantanément.

### L'Analogie du Monde Réel
> **L'Analogie du Cockpit d'Avion :** L'interface graphique est comme le tableau de bord simplifié d'une trottinette électrique : facile d'accès, mais très limité en vitesse et en contrôle. Le terminal est le **cockpit complet d'un avion de chasse** : chaque interrupteur a une fonction précise, et un pilote expérimenté peut accomplir des manœuvres complexes les yeux fermés en quelques fractions de seconde.

## 2. Les Raccourcis Clavier Magiques (Productivité x10)

Arrêtez d'appuyer cinquante fois sur la flèche gauche pour corriger le début d'une commande. Les shells modernes (Bash, Zsh) intègrent les raccourcis Readline d'Emacs :

```txt
┌───────────────┬────────────────────────────────────────────────────────┐
│ Raccourci     │ Action Immédiate                                       │
├───────────────┼────────────────────────────────────────────────────────┤
│ Ctrl + A      │ Déplace le curseur tout au début de la ligne           │
│ Ctrl + E      │ Déplace le curseur tout à la fin de la ligne           │
│ Ctrl + U      │ Efface toute la ligne avant le curseur                 │
│ Ctrl + K      │ Efface toute la ligne après le curseur                 │
│ Ctrl + W      │ Supprime le mot précédent immédiatement                │
│ Ctrl + R      │ Recherche instantanée dans l'historique des commandes  │
│ Ctrl + C      │ Interrompt et tue le processus au premier plan (SIGINT)│
│ Ctrl + L      │ Nettoie l'écran du terminal (équivalent de clear)      │
└───────────────┴────────────────────────────────────────────────────────┘
```

> **Le super-pouvoir de `Ctrl + R` :** Tapez `Ctrl + R`, puis commencez à taper un fragment d'une ancienne commande complexe (ex: `docker run`). Le shell retrouve instantanément la dernière commande correspondante. Appuyez à nouveau sur `Ctrl + R` pour remonter plus loin dans l'historique.

## 3. Variables d'Environnement et le fameux `$PATH`

Une application web moderne lit sa configuration via des **variables d'environnement** (`DATABASE_URL`, `PORT`, `NODE_ENV`).

### 3.1 Déclarer et Lire une Variable
```bash
# Définir une variable locale à la session actuelle
export API_KEY="sk_prod_99887766"

# Afficher la valeur de la variable
echo $API_KEY

# Lister toutes les variables d'environnement actives
env
```

### 3.2 Comprendre la variable `$PATH`
Lorsque vous tapez `node` ou `git`, comment votre terminal sait-il quel binaire exécuter ?
Il interroge la variable d'environnement **`$PATH`**, qui contient une liste ordonnée de répertoires séparés par deux-points (`:`) :

```bash
echo $PATH
# Exemple de sortie : /usr/local/bin:/usr/bin:/bin:/home/user/.cargo/bin
```

Si une commande affiche `command not found`, c'est que son binaire n'est pas situé dans l'un des dossiers de votre `$PATH`.

## 4. Diagnostic Réseau et Tests d'API avec `curl`

`curl` (*Client URL*) est l'utilitaire incontournable pour interroger des services distants sans ouvrir Postman ou votre navigateur.

```bash
# Requête GET simple avec affichage des en-têtes HTTP de réponse (-i)
curl -i https://api.github.com/users/octocat

# Requête POST avec corps JSON et en-tête d'authentification
curl -X POST https://api.bambadev.com/v1/auth/login \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer VOTRE_TOKEN" \
  -d '{"email": "dev@bambadev.com", "password": "SuperSecretPassword"}'

# Mesurer le temps exact de réponse d'un endpoint
curl -o /dev/null -s -w 'Temps total: %{time_total}s\n' https://bambadev.com
```

### Outils Réseau Complémentaires
- `ping google.com` : Teste la connectivité et la latence réseau avec un hôte distant.
- `dig bambadev.com` ou `nslookup bambadev.com` : Résout les enregistrements DNS d'un nom de domaine.
- `ssh utilisateur@serveur.com` : Ouvre une session chiffrée sur une machine distante.

## 5. Personnalisation : Les Alias pour Gagner du Temps

Un **alias** est un raccourci personnalisé vers une commande longue que vous utilisez quotidiennement.

Ouvrez votre fichier de configuration (`~/.zshrc` sous macOS ou distributions récentes, ou `~/.bashrc` sous Ubuntu/Debian) :

```bash
# Raccourcis Git vitaux
alias gs="git status"
alias ga="git add ."
alias gc="git commit -m"
alias gp="git push"
alias gl="git log --oneline --graph --decorate"

# Raccourcis Docker
alias dc="docker compose"
alias dps="docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'"

# Raccourcis Système
alias reload="source ~/.zshrc"
alias myip="curl ipinfo.io/ip"
```

Rechargez ensuite la configuration sans fermer le terminal :
```bash
source ~/.zshrc
```
